# PS2PC

**PS2PC** is a PlayStation 1 / PlayStation 2 controller adapter for PC.

It is designed for players who wish to use original PlayStation controllers on a modern Operating systems Like Windows, Linux, and Raspberry Pi, including support for XInput mode and pressure-sensitive PlayStation 2 buttons.

> Current status: **Beta**
>
> The hardware and software are functional, but compatibility notes, firmware/tools, and documentation may continue to improve.

---

## Features

- Use original PlayStation 1 and PlayStation 2 controllers on PC
- XInput mode for modern PC games
- Pressure-sensitive PlayStation 2 button support for compatible software
- Designed for retro gaming, emulator setups, and controller testing
- Simple Windows utility release provided as an `.exe`
- Ongoing compatibility and firmware/software updates
